# Machine Learning Zoomcamp

Personal exercises and homework for the
[DataTalksClub Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp).

## Repository structure

- `01-into/` — introduction, NumPy, pandas, and linear algebra
- `02-regression/` — linear regression exercises and homework
- `03-classification/` — classification and logistic regression exercises
- `04-evaluation/` — classification evaluation metrics and model validation
- `5-deployment/` — model serialization, APIs, environment management, and Docker
- `5-deployment/homework/` — 2026 deployment homework using FastAPI and `uv`
